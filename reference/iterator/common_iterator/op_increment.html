std::common_iterator::operator++(C++20)

common_iterator& operator++();    // (1) C++20

decltype(auto) operator++(int);   // (2) C++20

common_iterator operator++(int)
  requires forward_iterator<I> = default; // (3) C++29

概要

イテレータをインクリメントする。

堅牢化された事前条件

holds_alternative<I>(v_) == true

効果

I, Sの値のどちらかをvariant<I, S>型のメンバ変数v_に保持しているとして

  • (1) : 以下と等価

    ++get<I>(v_);
return *this;

  • (2) : 次のどちらかと等価

    • Iがforward_iteratorのモデルである場合

      common_iterator tmp = *this;
++*this;
return tmp;

    • それ以外の場合 : return get<I>(v_)++;

備考

  • (2), (3) : C++29で、Iがforward_iteratorのモデルとなる場合の後置インクリメントが、後置インクリメント・デクリメント演算のdefault定義を使用した= default定義のオーバーロード(3)として分離された。どちらの場合も動作は変わらない

例

#include <iostream>
#include <iterator>
#include <ranges>

int main() {
  auto seq = std::views::iota(1) | std::views::take(5);

  // common_iteratorを通すことでイテレータ型と番兵型を合わせる
  using CI = std::common_iterator<std::ranges::iterator_t<decltype(seq)>, std::ranges::sentinel_t<decltype(seq)>>;

  CI ci{std::ranges::begin(seq)};

  std::cout << *ci << std::endl;

  ++ci;

  std::cout << *ci << std::endl;

  ci++;

  std::cout << *ci << std::endl;
}
